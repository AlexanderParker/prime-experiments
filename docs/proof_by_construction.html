Twin Primes by Construction

Everything is built, not named. Each claim is followed by why the construction makes it so. State of the argument on 7 September 2026.

PROVED built here or in the kernel MEASURED zero exceptions on a stated range, no proof THEORISED not proved; if true, closes the conjecture

1The line and a gear PROVED

Take the counting numbers 1, 2, 3, … in a row: the line. A gear of size g is the rule "strike every g-th number": it strikes g, 2g, 3g, … and nothing else. A number is struck by a set of gears if at least one strikes it. A prime p is a number above 1 that no smaller number above 1 divides, so it is struck by no gear smaller than p, and by its own gear at p.

2The fold: what gears 2 and 3 leave PROVED

Run the gears 2 and 3. In each strip of six, 6j … 6j+5, gear 2 takes the even ones and gear 3 takes 6j and 6j+3. Only 6j+1 and 6j+5 survive. Pair the survivors as slots (6j−1, 6j+1): two numbers at distance 2. Every prime above 3 sits in a slot, and a twin prime pair is a slot with both members prime.

WhyOne strip of six checked by hand covers every strip, because the gears repeat every 6.

3Only the gears up to the square root decide a prime PROVED

If n < P² and no prime below P strikes n, then n is prime.

WhyIf n = a × b with 1 < a ≤ b, then a² ≤ n < P², so a < P, and the smallest prime factor of a is below P and strikes n. Contradiction.

4Cuts, sections, machines

Set c₁ = 3. Let p_k be the smallest prime at or above c_k, and set c_{k+1} = p_k². Section k is the numbers from c_k up to c_{k+1}. Machine k is the set of gears whose sizes are the primes in section k. Every prime above 2 belongs to exactly one machine, because the sections tile the line from 3 on.

5Inside a section only the machines below act: home strikes and echoes PROVED

Take n in section k+1, so p_k² ≤ n < p_{k+1}². By 3, n is prime exactly when no gear of machines 1 … k strikes it, since those are the primes below p_{k+1}. Now let a gear p ≥ p_{k+1} strike n, so n = p × c. Then c = n/p < p_{k+1}.

  • c = 1: n is the gear's own size. A home strike: the gear striking itself.
  • c > 1: c has a prime factor below p_{k+1}, a gear of machines 1 … k that already strikes n. An echo: a strike on a number a lower machine already struck.

So inside section k+1 the higher machines add nothing but their own sizes, and a slot that machines 1 … k leave unstruck has both members prime: it is a twin prime pair.

KernelOneStepE.new_iff, MachineStack.exhaust_home_or_echo; verified with 0 exceptions at 16 sections to q = 23.

6The hand-up: survivors become gears PROVED

By 4 the gears of machine k+1 are the primes in section k+1. By 5 those are exactly the numbers machines 1 … k leave unstruck there. So machine k+1 is built from the survivors of the machines below it, and one object has three names:

  • a twin prime pair in section k+1;
  • two gears of machine k+1 at distance 2;
  • a slot that machines 1 … k left open.
WhyAn identity of the construction; checked with 0 mismatches at 16 sections.

8The step THEORISED

For every k, the gears of machines 1 … k leave at least one slot of section k+1 unstruck.

By 6 that is the same as: machine k+1 has two gears at distance 2. In plain words: between every cut and its square there is a twin prime pair.

9The conclusion PROVED given 8

Machine 1 has a twin-gear pair (7). By 8, machines 1 … k leave a slot open in section k+1, which by 5 is a twin prime pair and by 6 a twin-gear pair of machine k+1. So every section holds a twin prime pair, the sections tile the line from 3 on, and there are infinitely many twin primes.

10What 8 cannot be built from PROVED, by building the counter-machines

  • Counting alone. Let each gear strike a shifted progression a+g, a+2g, … instead of its multiples. Such gears can be arranged to strike every slot of a section: 776 of the 1,226 gears below 10⁴ cover the first 60 cycles at q = 5. Any argument that uses only how much each gear strikes applies to them too. The real gears strike multiples; that difference must be used.
  • Multiples alone. "Strikes multiples" gives exactly the divisor property: an unstruck number has unstruck divisors, a struck number has struck multiples (0 violations in 107,750,211 tests). But the machine made of all primes below p_{k+1} plus the section's own twin primes as extra gears strikes multiples, has the divisor property, obeys every law on record, and leaves no open slot. What excludes it is only 4: a machine's gears are the survivors of the machines below, not an arbitrary set of primes.
  • So 8 must use the recursion of 6. Every argument so far treated the gears as given.

11The shape of what is missing

A property of a section's survivor set that is carried to the next section when the cut is squared, is not a count, and forces two survivors at distance 2. The only properties proved to carry across the squaring are counts: every machine removes half the numbers reaching it and a quarter of the slots (Mertens; measured to q = 23). Two candidates, neither built:

  • 11a Two gears at distance 2 strike the same slot earlier than any other pair, at (g+4)/3 in the folded coordinate, with deficit growing by exactly 4 per common period (proved, ArcFloor). So a machine with twin pairs strikes the start of the next section less than its size predicts. If that shortfall leaves one slot open before the machine's smallest gear engages, 8 holds and the twin pairs propagate themselves. Not measured.
  • 11b The property that separates a generated survivor set from an arbitrary divisor-closed set of primes on one section. It must be finer than any signed count: the parity-defined set (even number of prime factors) also has the divisor property and also kills the count, the signed slot census being 0.1% of slots against an 8% twin share. Not identified.
